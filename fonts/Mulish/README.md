# Mulish

Unmodified static Regular (400), Medium (500), SemiBold (600), and Bold (700) fonts from [googlefonts/mulish](https://github.com/googlefonts/mulish/tree/5503f7a18ce79870148b9f9cb8e592ac44c044c3/fonts/ttf).

Keep `OFL.txt` with the font files when publishing this folder. GABALLA's shared UI loads `fonts/Mulish/` from the assets repository, with that pinned upstream revision as a download fallback, and caches the files locally.
